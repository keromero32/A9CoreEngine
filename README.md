A9 Core

A lightweight Vulkan-based game engine for Android and mobile devices.

A9 Core is a custom game engine focused on fast, lightweight 3D rendering and Android development. The project is designed with performance, low-level rendering and mobile devices in mind.

Features

- 🎮 Vulkan-based rendering
- 📱 Android-focused architecture
- 🕹️ Mobile input support
- 🎥 Camera and movement systems
- ⚡ Lightweight and performance-oriented design
- 🛠️ C/C++ native components
- 📦 Android APK build support
- 🔧 Extensible engine architecture

Project Goals

The goal of A9 Core is to provide a simple and customizable foundation for creating games and interactive 3D applications on Android without relying on large commercial engines.

The engine is intended to be a flexible foundation for experiments, prototypes and custom game projects.

Build

The project can be built directly on Android using Termux, allowing development and APK generation without a PC.

bash termux-build.sh

The generated APK can then be installed directly on an Android device.

Status

🚧 Early Development

A9 Core is currently an experimental/custom game engine. APIs and systems may change as development continues.
